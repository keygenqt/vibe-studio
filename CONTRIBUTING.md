# Contributing

Thanks for your interest in Vibe Studio!

## Issues

Issues are the way to contribute to this project:

- **Bug reports** — describe the problem, steps to reproduce, expected and actual behavior.
- **Feature requests** — describe the use case, not just the solution.
- **Discussions** — any questions and ideas are welcome.

## Pull Requests

**Code contributions are not accepted.** The project has a single maintainer,
and keeping it that way preserves the right to relicense the code in the future.

If you have a fix or a feature in mind, please open an issue instead — it will
be implemented by the maintainer.
